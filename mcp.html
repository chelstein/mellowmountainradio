Background

How a mountain radio station got ahead of the networks

When most people think about a radio station’s technology, they picture a mixing board, a transmitter tower, maybe a streaming player on the website. KAZM has all of that. But it also runs something unusual for a small-market station: a live data infrastructure that’s been quietly powering one of the most feature-rich independent radio websites in the country.

Fire restriction levels from the Coconino National Forest, refreshed every six hours. Road conditions pulled from ADOT’s live feeds. Sedona weather straight from National Weather Service coordinates at the transmitter site. Concert tour dates for every artist in rotation, deduplicated and verified. A 14-day rewind archive, block by block. A song history going back to October 2023 that can answer what was playing at any minute since then.

All of that already exists. The MCP server simply opens a door into it.

The Technology

What MCP is, in plain terms

Model Context Protocol is Anthropic’s open standard for connecting AI assistants to live data and tools. Think of it as a USB port — but for knowledge. When an AI assistant needs real-world information to answer a question, it queries an MCP server. The server responds. The AI tells you, with the source intact.

“Right now, if you ask an AI ‘what are the fire restrictions in Sedona today?’ it either guesses, searches, or admits it doesn’t know. With KAZM’s MCP server, it knows.”

The protocol is model-agnostic and already supported by Claude and ChatGPT, with adoption moving fast across the AI ecosystem. A station that has an MCP server today is positioned the way a station with a strong website was positioned in 2002 — early enough that being there matters.

Why It Matters

Search indexes what you publish.
AI queries what you make available.

These are not the same thing, and the distinction will matter more with every passing year.

A page on a website gets discovered when someone searches for it. An MCP tool gets called when an AI needs it — which is increasingly whenever anyone asks a question. The shift from “I’ll Google it” to “I’ll ask Claude” is already in progress, and most media organizations haven’t thought about what that means for their distribution.

No other radio station — not iHeart, not NPR, not the big-market FM flagships with full engineering teams — has done this. That’s not an indictment of them. It’s an opportunity for KAZM. Being first in a distribution channel has historically been worth more than being second with a bigger budget.

And there’s a specifically local dimension here. When an AI helps someone plan a Sedona trip, or check road conditions before heading up Oak Creek Canyon, or ask about fire restrictions before lighting a campfire — KAZM is the answer. Real local data, properly attributed, in AI conversations instead of aggregator sites that scraped it from somewhere else.

Add KAZM manually — 4 steps
  1. 1 Copy KAZM’s config
    KAZM config
    { "mcpServers": { "kazm": { "url": "https://mcp.mellowmountainradio.com/mcp" } } }
  2. 2 Open the Claude config file In Claude Desktop: click Claude in the top menu bar → Settings → Developer → Edit Config. The file opens in a text editor automatically. Can’t find that menu? Open the file directly —
    Mac~/Library/Application Support/Claude/claude_desktop_config.json Win%APPDATA%\Claude\claude_desktop_config.json
  3. 3 Paste and save File is empty or just {}? Press Ctrl+A / ⌘+A, paste, save. Done. File already has "mcpServers" in it? Find that line and paste the "kazm" block inside it, alongside any existing entries. Save. File has other content but no "mcpServers"? Paste this block just before the last } in the file (add a comma after the line above it if there is one), then save:
    paste before the last }
    "mcpServers": { "kazm": { "url": "https://mcp.mellowmountainradio.com/mcp" } }
  4. 4 Quit Claude and reopen it Fully close Claude (don’t just minimize it), then open it again. That’s it — KAZM is now connected.
Then try it — ask Claude: “What song is playing on KAZM right now?” or “Are there any fire restrictions near Sedona?”
